# Assignment Write-Up

## 1. What was the most challenging part of this assignment? Did you find HTML and CSS easy or difficult to work with?

The most challenging part was making the crossword grid look clean, aligned, and visually consistent and still keep the layout simple and readable. HTML and CSS is easy overall, but adjusting layout details like spacing, sizing, and styling were the most frustrating parts.

## 2. How did you build the puzzle grid, and what other options did you consider?

I built the puzzle grid using a 5x5 CSS Grid layout. Each square was structured in HTML, with open cells containing a single-letter input and blocked cells styled as dark blocks. I used CSS to control the board spacing, alignment, and the placement of clue numbers. 

## 3. What did you take into account when designing the site? Is there anything you are particularly proud of?

I focused on keeping the site simple, readable, and elegant. I am proud of the color design and make the layout very clear.

## 4. Given more time or resources, what would you add?

I would add real game functionality such as win detection, and even more games.

## 5. How many hours did you spend on this assignment?

6–8 hours.
